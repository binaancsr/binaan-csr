# BINAAN CSR — Community Development Portal
Prototype website untuk repository GitHub `binaan-csr`.
Home dibuat minimalis dengan preview foto/produk untuk tahap berikutnya.
Website publik tidak menampilkan budget/pagu.
Sustainability Program menghitung jumlah program dan status pelaksanaan.
Status: Berjalan dengan Baik, Masih Berjalan, Perlu Perhatian, Mengalami Kendala, Tidak Berjalan, Belum Berjalan.

Upload `index.html` ke repository GitHub, kemudian import repository ke Vercel.
