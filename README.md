# Binaan CSR

Community Development Portal.

## Isi
- `index.html` — halaman utama website.
- Lokasi — peta interaktif dengan titik berwarna berdasarkan Summary Monev.
- Sustainability Program — dashboard dan filter dari Google Apps Script.
- Community Impact — dashboard, pencarian nama penerima/kelompok, filter gampong, dan tabel penerima manfaat.

## Status titik Lokasi
- Masih Berjalan
- Mati
- Tidak Berkembang/Kurang Baik
- Belum Monitoring

## Deployment
Upload `index.html` ke repository GitHub yang terhubung ke Vercel. README ini hanya dokumentasi proyek.
